# Verisure siren (research)

Photos of the Verisure siren's boards (CC1101 radio and others) and a general technical briefing
([Verisure_technical_briefing.md](Verisure_technical_briefing.md)). No firmware yet.

## Photos

The board has three main chips: a TI **MSP430F149** MCU, an **OKI L22901** and a TI **CC1101** radio.
